📖 How to Fix Neo4j Auth Errors

Option 1 — Find your password in Neo4j Desktop:

  1. Open Neo4j Desktop → click your database → Details tab.
  2. Your connection URI and credentials are shown there.
  3. Paste the password above and click Test & Save to .env.

Option 2 — Reset password via terminal:

# Stop Neo4j first, then:
neo4j-admin dbms set-initial-password neo4j123

# Then start Neo4j and use neo4j123 as your password above.

Option 3 — Edit .env manually:

# In your project root (.env):
NEO4J_URI=bolt://localhost:7687
NEO4J_USERNAME=neo4j
NEO4J_PASSWORD=<your_real_password>

After editing .env manually, restart the Flask server for changes to take effect, or use the Test & Save button above for a live update.
